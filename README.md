# 初级工程师：五年

一个以互联网公司初级技术人员为主角的单人策略模拟游戏。设计参考《维多利亚3》的信息密度与因果链，但把"国家"换成"一家小公司的数据库"。

> **技术知识是世界运行的规则，不是游戏里的考题。**

---

## 当前状态

**v0.9.0：长局自由经营。** 开局自选 W50~W100 的自动评价周，到点出一份**只作参考**的阶段性述职与数据成就，之后一直玩到角色失败；行动力与自学精力互相牵制；考核改成以写业务函数为主、按难度分题库；新增算法工程师路线；事件密度下调；新增启动主界面与跨局档案。

v0.9 新增：W50~W100 自选评价周与阶段性述职（数据成就 + 参考评级，不结束游戏）、行动点 ↔ 自学精力牵制（每周前 2 个动作不影响学习，之后每个动作让下周精力回复少 2 点，超过 5 个还会直接烧存量）、44 道考核题（24 编码 / 10 SQL / 4 配置 / 6 计算，编码题真的执行玩家写的 Python 函数逐用例判分）、简单 / 普通共基础题库而困难 / 老手各有加严变体、六条科技轨道 41 个节点（新增算法工程）、启动主界面（新的游戏 / 加载游戏 / 设置 / 沙盒模式 / 已解锁知识）与跨局知识图鉴、存档槽位管理。

```powershell
py -3 app.py                  # 打开 http://127.0.0.1:5000
py -3 -m pytest -q            # 120 项测试
py -3 tools/balance.py --seeds 20 --weeks 24   # 平衡扫描
```

命令行：

```powershell
py -3 sim_cli.py new   --seed 42 --slot dev      # 新游戏
py -3 sim_cli.py act   --list --slot dev         # 本周能做什么（含不可做原因）
py -3 sim_cli.py act   add_index_user_created --slot dev
py -3 sim_cli.py sim   --weeks 8 --slot dev      # 推进 8 周
py -3 sim_cli.py events --slot dev               # 事件因果树
py -3 sim_cli.py month --slot dev                # 月报（含绩效等级）
py -3 sim_cli.py preview --slot dev              # 分查询明细
py -3 sim_cli.py export --slot dev               # 导出完整状态 JSON
```

三条已验证的因果链：

- 不加干预推进 8 周：IOPS 75% → 96%，p95 138ms → 554ms，第 9 周开始超时。
- 加对 `(user_id, created_at)` 索引：订单查询 123ms → 2.2ms，但磁盘涨到 1.69GB、大屏仍是 951ms——**一个索引只解决一个瓶颈**。
- 不处理大屏：第 2 周触发「大屏又卡了 → 老板在群里 @ 你」，主管信任 −8；同样的链每 4 周复现一次，第 4 个月现金转负。

## 一句话说清它和"编程课"的区别

玩家不是"学习索引"，而是**老板的大屏每天早上卡住，全站跟着变慢**。他花一周时间打开慢查询日志，发现一条 `WHERE DATE(created_at)=...` 的 SQL 扫了 120 万行。他有四种修法：加缓存（快，但老板看到的数据会旧）、改 SQL（根治，但要改代码）、加只读副本（花钱，问题还在）、建汇总表（一劳永逸，但要维护定时任务）。

**没有一道题，没有一分经验值，但玩家必须真的理解索引才能选对。**

## 三个设计承诺

1. **不编数字。** 生产侧用显式成本模型（结构参考 InnoDB），常数由真实 MySQL 基准校准；考核判题在真实 SQLite 副本上执行玩家写的 SQL 并读执行计划。模型哪里是简化，[设计文档/SIMULATION_RULES.md](设计文档/SIMULATION_RULES.md) §19 逐条列出。
2. **不做题库。** 全游戏没有选择题、没有积分。科技树的考核不是"答对解锁下一关"，而是**把活干出来**：编码题要写一个真的能跑的 Python 业务函数（判题器逐用例调用它），SQL 题要在 20 万订单的真实 SQLite 副本上执行、`EXPLAIN` 不许出现 `SCAN`；跨周不交卷也算一次未通过。每条专精路线的结业考核都是编码题。[设计文档/GAME_DESIGN.md](设计文档/GAME_DESIGN.md) §14 有 10 条自检，不达标不算完成。
3. **不让 AI 决定世界。** 结算 100% 由确定性代码完成；AI 只能把已有事实写成人话，且默认关闭。
